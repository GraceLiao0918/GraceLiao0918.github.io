## 1. Generative Modeling As Sampling

### 1.1 数据对象向量化 (Objects as Vectors)
现代生成模型将现实世界的多模态数据抽象为高维欧氏空间中的实数向量 $z \in \mathbb{R}^d$：
- **图像 (Images)**：$z \in \mathbb{R}^{C \times H \times W}$（如 RGB 三通道图像 $C=3$）。
- **视频 (Videos)**：$z \in \mathbb{R}^{T \times C \times H \times W}$（在图像基础上引入时间离散帧轴 $T$）。
- **分子结构 (Molecules)**：$z \in \mathbb{R}^{3 \times N}$（$N$ 个原子在三维物理空间中的坐标集合）。
### 1.2 生成任务即概率采样 (Generation as Sampling)
在数学上，真实世界的数据分布被抽象为未知的概率密度函数 $p_{\text{data}}: \mathbb{R}^d \rightarrow \mathbb{R}_{\ge 0}$。
- **目标**：构建一个算法（生成模型），能够高效地从 $p_{\text{data}}$ 中抽取独立同分布样本 $z \sim p_{\text{data}}$。
- **训练代理**：训练阶段仅能访问经验数据集 $\mathcal{D} = \{z_1, z_2, \dots, z_N\} \stackrel{\text{i.i.d.}}{\sim} p_{\text{data}}$。

### 1.3 条件引导生成 (Guided Generation)
在实际应用中，生成往往受外部先验条件 $y \in \mathcal{Y}$ 控制（如文本提示词、类别标签）。
- 条件生成的目标是构造采样器 $z \sim p_{\text{data}}(\cdot \mid y)$。
- 理论范式：先建立无条件生成的严格动力学框架，再将其推广到包含条件变量 $y$ 的参数化场。

## 2. Flow and Diffusion Models

生成过程本质上是一个“将简单先验噪声分布 $p_{\text{init}}$ 传输变换至复杂数据分布 $p_{\text{data}}$”的动态连续变换系统。

### 2.1 常微分方程与流模型 (ODEs & Flow Models)
#### 2.1.1 数学定义
设速度场（向量场）为时变函数 $u: \mathbb{R}^d \times [0, 1] \rightarrow \mathbb{R}^d$，记为 $u_t(x)$。常微分方程 (ODE) 的初值问题 (IVP) 为：
$$\frac{d}{dt}X_t = u_t(X_t), \quad X_0 = x_0$$
其唯一解由积分流映射 (Flow Map) $\psi_t: \mathbb{R}^d \rightarrow \mathbb{R}^d$ 给出：
$$\psi_t(x_0) = x_0 + \int_0^t u_s(\psi_s(x_0))\, ds, \quad X_t = \psi_t(X_0)$$

#### 2.1.2 存在与唯一性定理
若向量场 $u_t(x)$ 连续可微且导数有界（全局 Lipschitz 连续），则对任意 $t \in [0, 1]$，流映射 $\psi_t$ 存在、唯一，且构成一个微分同胚（Diffeomorphism，即平滑双射且逆映射亦平滑）。

#### 2.1.3 流模型的生成机制
1. **随机初始化**：从易采样的先验分布（通常为标准各向同性高斯分布）采样 $X_0 \sim p_{\text{init}} = \mathcal{N}(0, I_d)$。
2. **ODE 数值积分**：利用神经网络参数化的向量场 $u_t^\theta(x)$，驱动轨迹演化到终端时间 $t=1$。
3. **终端判据**：训练目标要求流的推前分布满足 $X_1 = \psi_1^\theta(X_0) \sim p_{\text{data}}$。

```
[噪声空间 X_0 ~ N(0, I)] ---> 沿神经网络向量场 u_t(x) 积分 ---> [数据空间 X_1 ~ p_data]
```

### 2.2 随机微分方程与扩散模型 (SDEs & Diffusion Models)
#### 2.2.1 布朗运动 (Brownian Motion / Wiener 过程)
连续随机过程 $W = (W_t)_{t \ge 0}$ 满足：
1. $W_0 = 0$，轨道几乎处处连续。
2. **正态增量**：$\forall 0 \le s < t$，$W_t - W_s \sim \mathcal{N}(0, (t-s)I_d)$。
3. **独立增量**：任意不相交时间区间的增量相互独立。

#### 2.2.2 Itô 型 SDE 动力学
通过在漂移项（Drift）基础上引入由布朗运动驱动的扩散项（Diffusion），扩展动力学系统：
$$dX_t = u_t(X_t)\, dt + \sigma_t\, dW_t, \quad X_0 \sim p_{\text{init}}$$
式中 $\sigma_t \ge 0$ 为预设的标量扩散系数。
- **离散模拟（Euler-Maruyama 格式）**：
  $$X_{t+h} = X_t + h\, u_t(X_t) + \sigma_t \sqrt{h}\, \epsilon_t, \quad \epsilon_t \sim \mathcal{N}(0, I_d)$$
- **流与扩散的关系**：流模型是扩散模型在扩散项退化为零时的特例，即 $\sigma_t \equiv 0 \implies$ ODE 流模型。

## 3. Flow Matching

### 3.1 概率路径 (Probability Path)
概率路径是在概率测度空间中连接初始噪声分布与目标数据分布的一条光滑轨迹 $(p_t)_{t \in [0, 1]}$，满足边界条件：
$$p_0 = p_{\text{init}} = \mathcal{N}(0, I_d), \quad p_1 = p_{\text{data}}$$

#### 3.1.1 条件概率路径与边缘概率路径
直接对未知的整体边缘分布 $p_t(x)$ 进行建模极其困难。流匹配引入了基于单个样本 $z \sim p_{\text{data}}$ 的**条件概率路径** $p_t(x \mid z)$：
$$p_0(\cdot \mid z) = p_{\text{init}} = \mathcal{N}(0, I_d), \quad p_1(\cdot \mid z) = \delta_z$$
由全概率公式，全数据空间上的**边缘概率路径**为：
$$p_t(x) = \int p_t(x \mid z) p_{\text{data}}(z)\, dz$$

#### 3.1.2 高斯条件概率路径 (Gaussian Probability Path)
选用单调平滑的噪声调度函数 $\alpha_t, \beta_t$，边界满足 $\alpha_0 = 0, \beta_0 = 1$ 与 $\alpha_1 = 1, \beta_1 = 0$：
$$p_t(x \mid z) = \mathcal{N}(x;\, \alpha_t z,\, \beta_t^2 I_d)$$
对应闭式加噪采样过程：
$$z \sim p_{\text{data}}, \quad \epsilon \sim \mathcal{N}(0, I_d) \implies x_t = \alpha_t z + \beta_t \epsilon \sim p_t(x \mid z)$$

### 3.2 连续性方程与边缘化技巧 (Marginalization Trick)
#### 3.2.1 连续性方程 (Continuity Equation)
概率密度路径 $p_t(x)$ 与驱动该路径的无扩散 ODE 向量场 $u_t(x)$ 满足流体守恒定律：
$$\partial_t p_t(x) = - \operatorname{div}(p_t u_t)(x) = - \sum_{i=1}^d \frac{\partial}{\partial x_i} \big( p_t(x) u_t^i(x) \big)$$

#### 3.2.2 高斯条件向量场推导
设高斯条件流为 $\psi_t^{\text{target}}(x_0 \mid z) = \alpha_t z + \beta_t x_0$。对时间求导：
$$\frac{d}{dt}\psi_t = \dot{\alpha}_t z + \dot{\beta}_t x_0$$
利用反解关系 $x_0 = \frac{x - \alpha_t z}{\beta_t}$，代入即可消去初值 $x_0$，得到显式解析的**高斯条件目标向量场**：
$$u_t^{\text{target}}(x \mid z) = \left( \dot{\alpha}_t - \frac{\dot{\beta}_t}{\beta_t}\alpha_t \right) z + \frac{\dot{\beta}_t}{\beta_t} x$$

#### 3.2.3 边缘化定理 (Theorem 9)
定义边缘目标向量场为条件向量场在后验概率下的加权积分：
$$u_t^{\text{target}}(x) = \int u_t^{\text{target}}(x \mid z) \frac{p_t(x \mid z) p_{\text{data}}(z)}{p_t(x)}\, dz = \mathbb{E}_{z \sim p(z \mid x)} \left[ u_t^{\text{target}}(x \mid z) \right]$$
**证明概要**：
将上述积分代入连续性方程右端：
$$- \operatorname{div}\left( p_t(x) \int u_t^{\text{target}}(x \mid z) \frac{p_t(x \mid z) p_{\text{data}}(z)}{p_t(x)}\, dz \right) = - \int \operatorname{div}\big( p_t(\cdot \mid z) u_t^{\text{target}}(\cdot \mid z) \big)(x) p_{\text{data}}(z)\, dz$$
由条件场自身满足连续性方程，被积式等于 $\int \partial_t p_t(x \mid z) p_{\text{data}}(z)\, dz = \partial_t p_t(x)$。证毕。

### 3.3 条件流匹配损失 (CFM Loss) 与免模拟训练
#### 3.3.1 理想边缘流匹配损失
$$\mathcal{L}_{\text{FM}}(\theta) = \mathbb{E}_{t \sim \text{Unif}[0, 1],\, x \sim p_t(x)} \left[ \| u_t^\theta(x) - u_t^{\text{target}}(x) \|^2 \right]$$
该目标不可直接计算，因为边缘向量场 $u_t^{\text{target}}(x)$ 依赖于不可积的边缘密度分母 $p_t(x)$。

#### 3.3.2 替代方案：条件流匹配损失
$$\mathcal{L}_{\text{CFM}}(\theta) = \mathbb{E}_{t \sim \text{Unif}[0, 1],\, z \sim p_{\text{data}},\, x \sim p_t(x \mid z)} \left[ \| u_t^\theta(x) - u_t^{\text{target}}(x \mid z) \|^2 \right]$$

#### 3.3.3 等价性定理 (Theorem 12)
$$\mathcal{L}_{\text{FM}}(\theta) = \mathcal{L}_{\text{CFM}}(\theta) + C \quad (\text{其中 } C \text{ 与模型参数 } \theta \text{ 无关})$$
$$\nabla_\theta \mathcal{L}_{\text{FM}}(\theta) \equiv \nabla_\theta \mathcal{L}_{\text{CFM}}(\theta)$$
**核心物理内涵**：直接对解析的条件向量场做最小二乘回归，在期望意义下等价于拟合高度复杂的边缘向量场。这使得训练**完全无需进行 ODE 步进仿真 (Simulation-Free)**，极大降低了计算复杂度。

#### 3.3.4 直线最优传输调度 (CondOT / Rectified Flow)
在实践中，令 $\alpha_t = t, \, \beta_t = 1 - t$（此时 $\dot{\alpha}_t = 1, \dot{\beta}_t = -1$）：
$$x_t = t z + (1 - t) \epsilon, \quad u_t^{\text{target}}(x \mid z) = z - \epsilon$$
优化目标简化为极为优雅的均方误差回归：
$$\mathcal{L}_{\text{CondOT}}(\theta) = \mathbb{E}_{t, z, \epsilon} \left[ \| u_t^\theta(t z + (1 - t)\epsilon) - (z - \epsilon) \|^2 \right]$$
## 4. Score Matching & SDEs

### 4.1 分数函数与向量场的对偶转换
对于任意概率密度分布 $q(x)$，其**分数函数 (Score Function)** 定义为对数似然的一阶梯度：
$$s(x) := \nabla_x \log q(x) = \frac{\nabla_x q(x)}{q(x)}$$
几何意义：指向概率密度上升最陡峭的方向。

#### 4.1.1 高斯路径下的转换公式 (Proposition 1)
在高斯条件路径 $p_t(x \mid z) = \mathcal{N}(x; \alpha_t z, \beta_t^2 I)$ 下：
$$\nabla_x \log p_t(x \mid z) = - \frac{x - \alpha_t z}{\beta_t^2}$$
通过待定系数代数整理，流匹配向量场与分数函数存在精确代数对应关系：
$$u_t^{\text{target}}(x) = a_t \nabla_x \log p_t(x) + b_t x$$
$$a_t = \beta_t^2 \frac{\dot{\alpha}_t}{\alpha_t} - \dot{\beta}_t \beta_t, \quad b_t = \frac{\dot{\alpha}_t}{\alpha_t}$$

#### 4.1.2 去噪器重参数化 (Denoiser Formulation)
条件期望 $\mathbb{E}[z \mid X_t = x]$（后验干净数据均值）可表示为：
$$D_t(x) := \mathbb{E}[z \mid x] = \frac{1}{\dot{\alpha}_t \beta_t - \alpha_t \dot{\beta}_t} \big( \beta_t u_t^{\text{target}}(x) - \dot{\beta}_t x \big)$$

### 4.2 SDE 扩展定理与 Fokker-Planck 方程
#### 4.2.1 Fokker-Planck (Kolmogorov 前向) 方程
若随机过程遵循 Itô SDE：$dX_t = u_t(X_t)\, dt + \sigma_t\, dW_t$，其边际概率密度演化由二阶抛物型偏微分方程刻画：
$$\partial_t p_t(x) = - \operatorname{div}\big( p_t(x) u_t(x) \big) + \frac{\sigma_t^2}{2} \Delta p_t(x)$$
式中 $\Delta = \operatorname{div}(\nabla)$ 表示拉普拉斯算子。

#### 4.2.2 随机扩展定理 (Theorem 17)
已知保持概率路径 $p_t$ 的确定性 ODE 漂移为 $u_t^{\text{target}}(x)$。若任意给定非负连续扩散系数 $\sigma_t \ge 0$，则构造修正后的 SDE：
$$dX_t = \left[ u_t^{\text{target}}(X_t) + \frac{\sigma_t^2}{2} \nabla \log p_t(X_t) \right] dt + \sigma_t\, dW_t$$
**其边缘概率分布严格守恒**，在任何时刻依然满足 $X_t \sim p_t$。
- **推论**：通过在漂移项中加入朗之万修正漂移 $\frac{\sigma_t^2}{2}\nabla \log p_t$，生成过程可以在保边缘分布的前提下，随意调节随机探索强度 $\sigma_t$。

### 4.3 去噪分数匹配 (Denoising Score Matching)
直接学习边缘分数函数 $\nabla \log p_t(x)$ 时，类似流匹配，边缘分数匹配目标可等价替换为易处理的条件分数匹配目标：
$$\mathcal{L}_{\text{CSM}}(\theta) = \mathbb{E}_{t, z, x} \left[ \left\| s_t^\theta(x) - \nabla_x \log p_t(x \mid z) \right\|^2 \right]$$
代入高斯条件路径梯度 $\nabla_x \log p_t(x \mid z) = -\frac{\epsilon}{\beta_t}$，并引入噪声预测网络 $\epsilon_t^\theta(x) := -\beta_t s_t^\theta(x)$，即推导得到经典的 **DDPM** 训练目标：
$$\mathcal{L}_{\text{DDPM}}(\theta) = \mathbb{E}_{t, z, \epsilon} \left[ \| \epsilon_t^\theta(\alpha_t z + \beta_t \epsilon) - \epsilon \|^2 \right]$$
## 5. Guidance

### 5.1 朴素条件引导 (Vanilla Guidance)
将条件上下文（文本/类别）编码向量 $y$ 与时间 $t$、噪声状态 $x$ 一同输入神经网络，直接使用引导流匹配目标进行训练：
$$\mathcal{L}_{\text{CFM}}^{\text{target}}(\theta) = \mathbb{E}_{(z, y) \sim p_{\text{data}},\, t \sim [0, 1],\, \epsilon} \left[ \| u_t^\theta(x_t \mid y) - u_t^{\text{target}}(x_t \mid z) \|^2 \right]$$
- **瓶颈**：在没有额外引导的情况下直接采样，生成的样本往往无法高度贴合提示词（即文本对齐度较弱，模式覆盖范围过广）。

### 5.2 分类器引导 (Classifier Guidance) 与贝叶斯分解
根据贝叶斯法则：$p_t(x \mid y) = \frac{p_t(x) p_t(y \mid x)}{p_t(y)}$，对 $x$ 取空间梯度：
$$\nabla_x \log p_t(x \mid y) = \nabla_x \log p_t(x) + \nabla_x \log p_t(y \mid x)$$
将高斯路径下的代数转换关系代入，条件目标向量场可以显式分解为：
$$u_t^{\text{target}}(x \mid y) = u_t^{\text{target}}(x) + a_t \nabla_x \log p_t(y \mid x)$$
为了强制要求生成结果遵循条件 $y$，人为引入超参数 $w > 1$（引导尺度 Guidance Scale），对分类器似然梯度项进行线性放大：
$$\tilde{u}_t(x \mid y) = u_t^{\text{target}}(x) + w\, a_t \nabla_x \log p_t(y \mid x)$$

### 5.3 无分类器引导 (Classifier-Free Guidance, CFG)
由于在含噪数据上训练独立的辨别式分类器 $p_t(y \mid x)$ 成本高昂且在多模态（长文本）下难以提供鲁棒梯度，CFG 采用代数重配方将其消除：
$$\nabla_x \log p_t(y \mid x) = \nabla_x \log p_t(x \mid y) - \nabla_x \log p_t(x)$$
代入放大方程整理得：
$$\tilde{u}_t^w(x \mid y) = (1 - w) u_t^{\text{target}}(x) + w\, u_t^{\text{target}}(x \mid y) = u_t(x) + w \big( u_t(x \mid y) - u_t(x) \big)$$

```
无条件向量场 u_t(x)  -----------> [ + w · 差值向量 ] -----------> 增强向量场 ũ_t^w(x | y)
                             ^
条件向量场 u_t(x|y) ---------|
```

#### CFG 统一模型联合训练策略
通过引入空条件标记 $\emptyset$，将无条件生成视作特殊条件分支 $u_t^{\text{target}}(x) \equiv u_t^{\text{target}}(x \mid \emptyset)$：
- 在训练循环中，以一定概率 $\eta$（通常取 $10\% \sim 20\%$）随机将真实提示词 $y$ 替换为空标记 $\emptyset$。
- **推理期外推**：在前向步进中同时估算条件场与无条件场并做线性组合，以牺牲生成多样性为代价，显著提升图像与提示词的结构契合度与图像清晰度。

## 6. 大规模多模态生成架构：从数据空间到潜空间

### 6.1 条件特征嵌入机制 (Embeddings)
1. **时间编码 (Time Embedding)**：标量 $t$ 通过正余弦高频傅里叶特征投影为连续向量，确保网络敏锐感知去噪所处的动力学阶段：
   $$\text{TimeEmb}(t) = \sqrt{\frac{2}{d}} \big[ \cos(2\pi \omega_1 t), \dots, \sin(2\pi \omega_{d/2} t) \big]^T$$
2. **文本特征编码 (Text Conditioning)**：
   - **全局对齐**：使用预训练 CLIP 模型获取单一全局语义嵌入向量 $y_{\text{CLIP}}$。
   - **细粒度对齐**：使用 T5 / ByT5 / UL2 等大型语言模型，保留由 Token 序列构成的特征矩阵，用于细粒度交叉注意力交互。

### 6.2 主干网络演进：U-Net 到 Diffusion Transformer (DiT)
#### 6.2.1 传统 U-Net 局限
U-Net 依赖下采样-上采样卷积层与跨层跳跃连接（Skip Connections）。当参数扩展到数十亿级别以及需要同时建模多模态长上下文时，局部卷积归纳偏置会限制其泛化能力与吞吐速度。

#### 6.2.2 DiT 核心机制 (adaLN-Zero 与 Cross-Attention)
DiT 将含噪图像切分为 Patch 并展平成一维序列（Tokenization），利用标准 Transformer 堆叠。
- **自适应层归一化 (adaLN-Zero)**：时间与全局条件向量通过轻量 MLP 回归出缩放/平移系数 $(\gamma, \beta)$ 及门控权重 $\alpha$：
  $$\text{adaLN}(x) = (1 + \gamma) \odot \text{LayerNorm}(x) + \beta$$
- **多模态交叉注意力 (MM-DiT)**：如 Stable Diffusion 3 所示，图像 Token 与文本 Token 分别享有独立的注意力参数映射，但在自注意力层中互相混合计算注意力权重矩阵，实现双向模态特征的深度对齐。

```
图像特征流: [Patch 序列] ---> LayerNorm(adaLN) ---> Q_img \
                                                           (混合注意力) ---> 输出更新
文本特征流: [Text 序列]  ---> LayerNorm(adaLN) ---> K,V_txt /
```

### 6.3 潜空间生成范式：变分自编码器 (VAE) 的必要性
#### 6.3.1 维数灾难与两阶段分离
直接在像素空间训练高分辨率流模型（如 $1024 \times 1024 \times 3 \approx 3.1 \times 10^6$ 维）在显存与吞吐上不可行。
- **第一阶段（感知压缩）**：训练 VAE / GAN 自编码器，将空间冗余压缩至低维潜空间（例如下采样 8 或 16 倍）。
- **第二阶段（语义生成）**：在紧凑且几何结构规整的潜变量空间中训练 Flow/Diffusion 模型。

#### 6.3.2 VAE 数学目标与重参数化
设编码器为 $q_\phi(z \mid x) = \mathcal{N}(\mu_\phi(x), \operatorname{diag}(\sigma_\phi^2(x)))$，解码器为 $p_\theta(x \mid z)$，先验为 $p_{\text{prior}}(z) = \mathcal{N}(0, I_k)$。
- **证据下界损失 (ELBO)**：
  $$\mathcal{L}_{\text{VAE}}(\phi, \theta) = \underbrace{\mathbb{E}_{x, z \sim q_\phi(z \mid x)} \left[ \frac{1}{2\sigma^2} \| x - \mu_\theta(z) \|^2 \right]}_{\text{重建误差 (Distortion)}} + \beta \underbrace{\mathbb{E}_x \left[ D_{\text{KL}}\big( q_\phi(z \mid x) \,\|\, \mathcal{N}(0, I) \big) \right]}_{\text{潜空间正则项 (Rate)}}$$
- **重参数化技巧 (Reparameterization Trick)**：
  $$z = \mu_\phi(x) + \sigma_\phi(x) \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I_k)$$
  将随机性从计算图中剥离，使得梯度能够反向传播至编码器参数 $\phi$。

#### 6.3.3 率失真权衡与分工哲学 (Rate-Distortion Pareto Frontier)
- **过小 $\beta$（高 Rate，极低 Distortion）**：重建保真度高，但潜空间分布形态极不规则，导致下游扩散模型难以拟合。
- **过大 $\beta$（极低 Rate，高 Distortion）**：潜空间趋于完美高斯，但解码出现严重后验崩溃，图像模糊。
- **黄金折衷点**：位于 Pareto 边界的弯折拐角点（"Knee" 区域），利用轻微的潜空间正则约束确保生成模型易学，同时借助感知损失（Perceptual Loss）保留图像高频细节。

## 7. 离散扩散模型：连续时间马尔可夫链 (CTMC) 与语言建模

### 7.1 离散状态空间与跳跃速率矩阵 (Rate Matrix)
当数据为离散序列（如词元文本、DNA 序列）$S = \mathcal{V}^d$ 时，无法定义向量场导数，因而引入连续时间马尔可夫链 (CTMC)。
- **微观转移速率**：由速率矩阵 $Q_t(y \mid x)$ 刻画状态跳转强度（$x, y \in S$）：
  $$Q_t(y \mid x) \ge 0 \quad (y \ne x), \quad Q_t(x \mid x) = - \sum_{y \ne x} Q_t(y \mid x)$$
- **无穷小状态跃迁概率**：
  $$p_{t+h \mid t}(y \mid x) = \mathbb{I}_{\{y = x\}} + h\, Q_t(y \mid x) + \mathcal{O}(h)$$

### 7.2 柯尔莫哥洛夫前向方程 (Kolmogorov Forward Equation, KFE)
CTMC 的边际分布演化遵循如下常微分方程系统（连续性方程的离散形式）：
$$\frac{d}{dt} p_t(x) = \sum_{y \in S} Q_t(x \mid y) p_t(y) \iff \frac{d}{dt} p_t = Q_t p_t$$

### 7.3 可解离散流匹配体系
#### 7.3.1 独立混合路径 (Factorized Mixture Path)
通过单调标量调度函数 $\kappa_t \in [0, 1]$（$\kappa_0 = 0, \kappa_1 = 1$），在每个 Token 维度上独立施加状态覆盖：
$$p_t(x \mid z) = \prod_{j=1}^d \big[ (1 - \kappa_t) p_{\text{init}}^{(j)}(x_j) + \kappa_t \delta_{z_j}(x_j) \big]$$

#### 7.3.2 离散边缘化定理 (Discrete Marginalization Trick)
构造条件转移矩阵 $Q_t^z(y \mid x)$ 驱动条件路径，则边缘转移速率矩阵由下式给出：
$$Q_t(y \mid x) = \sum_{z \in S} Q_t^z(y \mid x) \frac{p_t(x \mid z) p_{\text{data}}(z)}{p_t(x)} = \sum_{z \in S} Q_t^z(y \mid x) p(z \mid x)$$

#### 7.3.3 离散流匹配损失 (DFM Loss)
在因式分解的混合路径下，边缘速率矩阵被简化为**对终端真实 Token 的分类概率预测**：
$$Q_t(v, j \mid x) = \frac{\dot{\kappa}_t}{1 - \kappa_t} \big( p(z_j = v \mid x) - \delta_{x_j}(v) \big)$$
此时，神经网络 $p_{1|t}^\theta(v \mid x)_j$ 的学习目标转化为在任意加噪时刻 $t$ 对原始离散序列的多分类交叉熵损失：
$$\mathcal{L}_{\text{DFM}}(\theta) = \mathbb{E}_{z \sim p_{\text{data}},\, t \sim [0, 1],\, x \sim p_t(\cdot \mid z)} \left[ \sum_{j=1}^d - \log p_{1|t}^\theta(z_j \mid x)_j \right]$$

#### 7.3.4 掩码扩散语言模型 (Masked Diffusion Language Models, MDLM)
在词表中引入特殊掩码标记 $\text{[MASK]}$，设定初值分布为全掩码序列 $p_{\text{init}} = \delta_{[\text{MASK}]^d}$。生成过程即从全序列 $\text{[MASK]}$ 开始，根据模型预测逐步反解、去掩码填补内容，支持全序列全局双向协同生成。

## 核心算法流程速查

### 算法 A：基于高斯直线的条件流匹配训练 (Flow Matching Training)
```python
def train_step_flow_matching(z, model, optimizer):
    # 1. 采样时间与基底噪声
    t = torch.rand(z.shape[0], 1, 1, 1)  # t ~ Unif[0, 1]
    eps = torch.randn_like(z)              # eps ~ N(0, I)
    
    # 2. 构造高斯 CondOT 插值状态及解析目标速度场
    x_t = t * z + (1.0 - t) * eps
    u_target = z - eps
    
    # 3. 计算均方误差损失并更新网络
    u_pred = model(x_t, t)
    loss = torch.mean((u_pred - u_target) ** 2)
    
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    return loss.item()
```

### 算法 B：欧拉法流模型采样 (Flow ODE Sampling with Euler)
```python
@torch.no_grad()
def sample_flow_euler(model, shape, num_steps=50):
    dt = 1.0 / num_steps
    # 1. 初始化纯高斯噪声
    x = torch.randn(shape)
    
    # 2. 从 t=0 沿预测场积分至 t=1
    for step in range(num_steps):
        t = torch.full((shape[0], 1, 1, 1), step * dt)
        u_pred = model(x, t)
        x = x + dt * u_pred  # 欧拉前进步进
        
    return x  # 返回生成结果 X_1 ~ p_data
```
