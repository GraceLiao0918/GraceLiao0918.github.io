# Codex的安装与使用

## 概述

Codex 是 OpenAI 推出的面向代码场景的 AI 编程工具，同类型工具还有 Cursor、Claude Code，可辅助代码生成、代码解释、程序调试等开发工作。

## 前置准备

使用 Codex 前，需要提前配置好以下环境：
- node.js
- git
- VSCode

## 获取方式

官方页面：[ChatGPT 中的 Codex | 面向软件工程的 AI 编程智能体 | OpenAI](https://openai.com/zh-Hans-CN/codex/)

## 当前遇到的卡点

完成账号登录之后，平台要求绑定境外手机号码，这是目前使用过程中遇到的阻碍。
